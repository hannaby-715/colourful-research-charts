Fourteen charts, one renderer

Every chart below was produced by render.py on real data, with no chart library: pure Python standard library writing SVG, wrapped in a single self-contained HTML file. Palette and font are set per chart, or at random.

How to reproduce any of these. One command each, all listed in SKILL.md. The renderer is Python standard library only: no matplotlib, no Node, no Chrome, no API key, no network. Output is always a single HTML file.
